Solo-building a FastAPI MVP ("Voice-to-Text Timestamp API") from scratch in an empty, not-yet-git repo. Comfortable proposing a detailed, well-reasoned architecture up front (see [[project-architecture]]) and asking for critique rather than open-ended brainstorming — prefers tight, direct go/no-go answers with top risks over long-form advisory writeups when the design is already mostly settled.

Development machine is CPU-only (Ryzen 5 Mobile, 16GB RAM, no GPU) — this is also presumably the deployment target given the "MVP" framing and explicit hardware constraint in the brief. Treat CPU/RAM efficiency as a first-class constraint in any suggestion, not an afterthought.
